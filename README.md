# Family Benefits & 401K Calculator
Full-stack application for comparing compensation packages, modeling 401K growth, and evaluating family benefits across employers.

The application will allow users to compare salary, retirement benefits,
healthcare benefits, parental leave, pensions, and projected 401K growth.

## Goals

This project is being built to help me explore full-stack application development using the following frameworks, tools, and concepts:

- Angular
- TypeScript
- Node.js
- Express
- PostgreSQL
- REST API design
- Authentication and authorization
- Financial calculation services
- Automated testing
- CI/CD
- Cloud deployment
